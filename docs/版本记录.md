# Earthquake Show 版本记录

## 维护规则

本文档长期记录每个版本实际完成的小功能，是判断某个版本“已经具备什么能力”的唯一版本清单。

- 每次新增、修改或移除用户可见功能时更新本文档。
- 每个版本必须记录实现内容、明确未包含内容、验证结果和已知问题。
- 正式原生版本号统一维护于 `Directory.Build.props`，并由各 `.csproj` 和界面版本信息读取。
- 尚未实现或尚未验证的能力不得写入“已实现”。
- Bug 修复除记录在这里外，还要在[工程实现文档](./工程实现文档.md)的故障记录中说明原因和验证方法。

## 0.30.0 - 2026-08-21

### 已实现

- 地图入口切换为 JMA 地震信息细分区域 GeoJSON，不再使用手工日本示意轮廓。
- `OfflineMapGeometry` 完整读取 Polygon/MultiPolygon 的全部外环和内环；同一 Feature 的多岛屿合并为一个可绘制几何，并提供资源范围和无效几何诊断。
- WPF 地图改用 `Path`/`StreamGeometry` 的 EvenOdd 填充规则，保留岛屿和洞；投影范围从真实资源计算并加入纬度纵横比修正，事件点也会纳入范围。
- 地震区域按 `IntensityArea.Code` 聚合匹配同码几何，未匹配区域通过 `UnmappedAreaCount` 保留诊断，不静默丢弃。
- 优化 JMA 地震区域概览资源：调整为 `0.015` 度简化容差和 `0.0002` 平方度最小多边形面积过滤，在控制内存增长的同时减少海岸线缝隙；资源约 3.2 MB，高精度资源仍保留为后续按需加载输入。
- 调整地图配色：海洋使用蓝色背景，陆地使用浅暖色填充，边界使用较深蓝灰线条，震度区域颜色保持原定义。

### 本版本未包含

- 不修改观测点目录；当前仍使用随应用复制的 75 个固定测试站点坐标，完整站点代码目录和三层树 UI 留在后续步骤。
- 不接入 EEW、海啸或历史回放地图图层，不引入 Mapsui/SkiaSharp 运行时依赖；概览地图允许忽略极小岛屿和碎片，不能用于精确空间分析。

### 验证结果

- 新增多环、多岛屿和无效几何诊断测试；App 67 项测试通过。
- Core 68、Infrastructure 37、App 67，共 172 项测试通过；Release 构建 0 警告、0 错误。
- 真实地震区域资源校验：194 个 Feature，几何类型为 Polygon/MultiPolygon，范围约为经度 122.93–153.99、纬度 20.42–45.56。
- 概览资源校验：194 个 Feature、435 个多边形部件、约 3.2 MB；启动入口已切换到该资源。
- 固定测试数据校验和 GIS 转换器自测通过。

提交日志建议：`0.30.0: 接入JMA真实地震地图`

- 保存同一 JMA 事件 `20260819071048` 的官方 `VXSE51`、`VXSE52` 和 `VXSE53` XML 原文，覆盖震度速報、震源情报和震源/震度详情链路。
- 官方 `VXSE53` 样本包含 4 个都道府县、7 个细分区域、41 个市町村和 75 个观测点，可用于多区域及多观测点解析测试。
- 增加基于官方 `VXSE53` 的订正夹具，保留同一 `EventID`，使用 `InfoType=訂正`、`Serial=2` 和修正后的震级。
- 增加字段缺失夹具，覆盖震级 `NaN`、震源无坐标、可选字段缺失和观测点坐标无法补齐。
- 从 JMA 官方震度观测点坐标 JSON 筛选并关联详情报中的 75 个观测点编码，生成离线 `JmaStations.csv`。
- 根据官方观测点坐标生成 7 个区域测试包络 GeoJSON，用于区域编码匹配和离线图层加载验证；文件明确标记为非官方边界。
- 增加 `unknown` 到震度 `7` 的标准化、排序和应用显示颜色定义；颜色只作为辅助编码。
- 增加数据清单，记录官方/合成来源、下载日期、SHA-256 和每份报文的预期结果。
- 增加无第三方依赖的离线校验脚本，检查哈希、XML 事件链、订正状态、缺失字段、观测点、GeoJSON 和震度定义。
- 修复校验器将 XML `NaN` 保留为浮点值的问题，详见工程实现文档 `BUG-002`。

### 本版本未包含

- 固定数据尚未接入 WPF 页面，没有新增用户可见的地震事件。
- 尚未实现 JMAXML 解析器、统一领域模型、事件合并或报文排序。
- 区域 GeoJSON 是测试包络，不是 JMA 官方细分区域边界，不得用于正式地图或区域归属判断。
- 未加入 xUnit 工程；本步骤验证的是静态数据契约和完整性，使用独立离线校验脚本更直接。

### 验证结果

- `python tools\validate_test_data.py`：通过，验证 5 份 XML、75 个观测点、7 个区域测试包络和 10 个震度定义。
- 三份官方报文具有同一 `EventID`；订正夹具归属于同一事件；缺坐标观测点未出现在坐标表中。
- 所有固定文件的 SHA-256 与 `manifest.json` 一致，校验过程未访问网络。
- `dotnet build EarthquakeShow.sln --configuration Release --no-restore`：通过，`0` 个警告、`0` 个错误。

### 已知限制

- JMA 官方细分区域 Shapefile 约 110 MB，本版本没有将其纳入测试数据；正式地图阶段只提交经简化和许可核验的派生资源。
- 合成夹具用于边界行为测试，不代表 JMA 实际发布事件，也不替代完整 JMAXML Schema 验证。

## 0.2.0 - 2026-08-19

### 已实现

- 建立 `EarthquakeShow.sln` 和 `EarthquakeShow.App` WPF 工程，目标框架为 `.NET 8 Windows`，输出类型为 `WinExe`。
- 使用 WPF 原生 `Window`、`Grid`、`RadioButton`、`TabControl` 等控件实现地震情报页面外壳，不启动浏览器、WebView 或本地 Web 服务。
- 主窗口包含顶部应用状态、左侧地震导航、事件列表空状态、地图占位区、摘要/观测点/时间线/原始数据四个详情标签和底部状态栏。
- 默认窗口尺寸为 `1440 × 900`，最小尺寸为 `1180 × 720`。
- `MainWindowViewModel` 每秒更新一次 JST 时间，并显示网络、缓存和程序版本占位状态；窗口关闭时停止计时器。
- 使用 `Directory.Build.props` 统一维护 `0.2.0` 程序版本、可空引用、隐式 using、警告即错误和确定性构建设置。
- 修复启动时版本文本绑定到只读属性导致的异常，详见工程实现文档 `BUG-001`。

### 本版本未包含

- 未加入固定或实时地震报文、事件领域模型、合并逻辑和历史数据。
- 未引入 Mapsui/SkiaSharp、SQLite、CommunityToolkit.Mvvm 或其他外部 NuGet 依赖。
- 地图按钮为禁用占位控件；EEW、海啸、搜索、设置和历史回放入口尚未显示。
- 当前没有适合单元测试的领域或数据逻辑，因此未建立测试工程；将在固定报文解析和事件合并逻辑出现时加入 xUnit 测试。

### 验证结果

- `dotnet build EarthquakeShow.sln --configuration Release`：通过，`0` 个警告、`0` 个错误。
- 原生进程 `EarthquakeShow.App.exe` 成功启动，窗口标题为 `Earthquake Show`，未启动浏览器或服务器。
- 实测默认窗口为 `1440 × 900`；请求缩小至 `800 × 600` 时，WPF 正确限制为 `1180 × 720`。
- 通过 Windows UI Automation 验证四个详情标签均存在，可切换至“时间线”并恢复“摘要”。
- 主窗口正常关闭，进程在 5 秒内退出，`dotnet run` 返回代码 `0`。
- 已检查 `1440 × 900` 截图，未发现空白渲染、文字裁切、控件重叠或越界。

### 已知限制

- 当前页面只展示无数据状态，尚不能加载或查看真实地震事件。
- UI 响应式收缩、地图渲染和高 DPI 场景将在对应实现步骤单独验证。
